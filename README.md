A token launch radar: from one frozen snapshot it ranks 198 protocols that have no token yet by their implied launch market cap — TVL times a peer multiple adjusted for growth, maturity and reach — and ships a fully offline dashboard (search, filters, per-protocol detail) whose every number recomputes from the same data the program emits. Deterministic, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
